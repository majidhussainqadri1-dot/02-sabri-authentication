# R316 — Sessions, Authentication Assurance, Professional Reauthentication and Access Review

Review baseline: `a5d4b0e0ac2959d67b13fc49f37a659e64276eae`.

Method: session projection/revocation, authentication assurance, professional reauthentication, unmanaged-authentication access control, Safe Mode challenge invalidation and related regression coverage were reviewed completely before correction. The defect ledger was then frozen and corrected as a batch.

Defects found:
1. CF-01 authentication assurance consumed the retired `SAUTH_Passkeys::file00_assurance()` projection directly instead of the hardened epoch-aware `SAUTH_Passkey_Runtime::current_assurance()` provider. That could bypass the current assurance-epoch invalidation boundary.
2. `revoke_user_sessions()` cast a failed session-registry COUNT postcondition read to zero and could report successful registry reconciliation after a read failure.

Corrections: bind authentication assurance to hardened current passkey runtime; fail session revocation closure on postcondition DB uncertainty; update the CF-01 unit fixture to the current provider; add `tests/r316-session-assurance-hardening-regression.php`.

Correction workflow run: `31810665399` — success. Product correction commit: `afda86f7d0ee087210bcb0a625a6417c810550f1`.
